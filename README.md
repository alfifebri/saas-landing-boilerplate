#  SaaSify - React & Tailwind SaaS Landing Page Boilerplate

A clean, modern, and production-ready SaaS landing page template built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

##  Quick Start

1. **Install Dependencies:**
   ```bash
   npm install

2. **Run Development Server:**
   ```bash
   npm run dev

3. **Build for Production:**
    ```bash
    npm run build

## Customization

You can easily edit all text, features, pricing plans, and FAQ content without touching the UI code.
Simply edit the configuration file located at:
src/data/content.js

## Tech Stack
1. React (Vite)
2. Tailwind CSS
3. Lucide React (Icons)
4. Framer Motion (Animations)
